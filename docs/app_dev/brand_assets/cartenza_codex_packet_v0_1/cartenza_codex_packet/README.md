# Cartenza Visual Identity Handoff Packet

**Project:** Cartenza / Music Taste Atlas
**Status:** Working visual direction for Alpha / design implementation exploration
**Date:** 2026-05-23

This packet packages the current working direction for the app formerly referred to as Waymark.

## Current brand decision

Use **Cartenza** as the working app brand for now.

## Selected logo direction

The preferred master direction is **Concept 5: circular cartographic monogram / compass-seal C**.

Use Concept 5 as the primary logo/app-icon direction, while borrowing Concept 1's topographic contour texture for secondary backgrounds, Atlas surfaces, and supporting visual motifs.

## Included folders

```text
assets/reference/      PNG reference boards from the six generated concepts
assets/svg/            Starter vector approximation files for implementation exploration
assets/png/            Rendered PNG previews from starter SVGs
docs/                  Product/design guidance and implementation notes
tokens/                Color/type/elevation tokens

```

## Important caveat

The generated PNG boards are **directional references**, not final production artwork. The SVG files included here are **starter approximations** intended to help Codex or a designer implement the direction in-app. Final vector cleanup should be done by design before public release.
