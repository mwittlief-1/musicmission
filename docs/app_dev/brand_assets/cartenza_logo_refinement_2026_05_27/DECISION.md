# Cartenza Logo Decision - 2026-05-27

Decision: lock Candidate B, `Cartographic Cut`, as the Alpha logo direction.

- SVG: `assets/svg/cartenza_logo_selected.svg`
- PNG preview: `assets/png/cartenza_logo_selected.png`

These selected aliases currently match:

- `assets/svg/cartenza_logo_candidate_b_cartographic_cut.svg`

## Rationale

Candidate B is the strongest correction to the initial Concept 5 mark:

- more ownable Cartenza monogram
- less literal compass/seal detail
- better relationship to cartographic contour language
- still compatible with the Night Vision palette
- likely easier to mature into final vector artwork

## Not Included In This Decision

- Runtime app icon replacement
- SwiftUI mark replacement
- App Store/TestFlight metadata updates
- Final public-release vector cleanup

Those should be handled as separate implementation and design-finalization slices.
