# Alpha Packets

This directory is for accepted alpha integration packets that are small enough to keep in the repo and useful as deterministic app-import or backend-contract fixtures.

## Tracked

- `golden_alpha_packet_v0_1/` is the current golden end-to-end packet from survey evidence through mission-generation response and app-importable `mission.v0.2` JSON.

## Not Tracked By Default

- Timestamped generation attempts.
- Zip bundles.
- Raw model/API logs that are not part of an accepted golden packet.

Promote a generated packet here only when it has a manifest, validation notes, and a clear fixture or contract purpose.
