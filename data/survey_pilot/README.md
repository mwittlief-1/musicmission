# Survey Pilot

This directory contains accepted survey-pilot integration evidence used to validate the controlled path from repaired canonical graph inputs into survey pages and response logs.

## Tracked

- `v0_1/` is the current accepted pilot snapshot. It is small, deterministic, and documented by `survey_pilot_manifest.json`.

## Not Tracked By Default

- Timestamped pilot reruns.
- Raw app/device exports.
- Large response dumps that are not tied to an accepted pilot manifest.

Promote new pilot material only when the manifest states the source inputs, acceptance status, and review purpose.
